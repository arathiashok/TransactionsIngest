# Transaction Ingest frontend

Standalone Angular application generated with Angular CLI 22.2.4. It uses TypeScript and plain CSS, without routing, server-side rendering, or test tooling.

## Install dependencies

```sh
npm ci
```

## Start locally

```sh
npm start
```

Open http://localhost:4200/. The development server reloads when source files change.

## Production build

```sh
npm run build
```

Output is generated in `dist/transaction-ingest/browser/`. Dependencies, build output, and Angular caches are ignored by Git.
